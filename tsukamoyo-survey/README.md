友人に職場環境について聞くための、スマートフォン対応の静的サイトです。既存の GitHub Pages サイトのサブディレクトリに追加されています。

公開用 URL: https://chocoppu.github.io/tsukamoyo-survey/

質問は10問（1・2・3・6・8の5問が必須）です。

フォームの送信先は n78777132@gmail.com です。メール送信は FormSubmit (https://formsubmit.co/) を使用しており、GitHub Pages にサーバーを設置する必要はありません。

## 最初の一回だけ必要な設定

FormSubmit をこの送信先で初めて使う場合は、まず自分でサイトを開いてテスト回答を送信してください。送信先の Gmail に届く FormSubmit の確認メールを開いて有効化すると、その後の回答メールを受信できます。迷惑メールフォルダも確認してください。

有効化前の回答はすぐに届かない場合があります。FormSubmit は有効化後に未送信だった回答をメールで配送する仕組みを案内しています。

公開 URL が表示されない場合は、GitHub の Chocoppu/chocoppu.github.io リポジトリの Settings → Pages で GitHub Pages の公開元設定を確認してください。既存の2つのフォルダは変更していません。

## プライバシー

送信内容は外部サービス FormSubmit を経由します。同サービスは回答を一定期間保存する場合があります。メールアドレスは静的 HTML に記載されるため公開されます。フォームにはFormSubmit標準のスパム判定とreCAPTCHAが適用されます。端末による誤判定を切り分けるため、追加の任意honeypot欄は削除しました。万一配信されない場合に備え、送信前に回答をコピーできるボタンを設けています。スパムが完全に防げるとは限りません。氏名・連絡先・機密情報は入力しないでください。
